# Storyboard Jam

A collaborative, offline-first storyboard & animatic tool built in JavaScript.
- Draw frames, arrange timeline, and export animatics — all stored locally (IndexedDB).
- Optional peer-to-peer real-time collaboration via WebRTC.

## Features
- Canvas editor with brush/eraser/text
- Frame timeline with durations
- Offline-first (IndexedDB + Service Worker)
- P2P collaboration (WebRTC)
- Export to GIF / WebM
- Import / export project JSON

## Tech
Vanilla JS (or React/Vue/Svelte), IndexedDB, WebRTC, Service Worker, gif.js
